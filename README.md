> Please open issues and pull requests there.  
> **Mirrors:** [Codeberg](https://codeberg.org/ImL1s/android-demo-slots) · [GitLab](https://gitlab.com/aa22396584/android-demo-slots)


A modernized Slot Machine Proof of Concept (POC) for Android, featuring smooth animations, sound effects, and the latest Android development standards.

## ✨ Features
- **Wheel Animations**: Smooth spinning effects powered by Kotlin Coroutines.
- **Sound Effects**: Immersive audio feedback for starting and stopping.
- **Modern Stack**: Fully migrated to AndroidX and Kotlin 2.0.
- **Robustness**: Type-safe interactions with View Binding.

## 🛠️ Technology Stack
- **Language**: Kotlin 2.0.21
- **Asynchronous**: Kotlin Coroutines
- **UI Architecture**: View Binding
- **Build System**: AGP 8.7.3 / Gradle 8.10.2
- **Test Framework**: JUnit 4 / Espresso

## 🚀 Getting Started
1. Clone the repository.
2. Open in Android Studio.
3. Build and run on a device with API 35+.

## 🧪 Testing
Run tests using:
```bash
./gradlew test connectedAndroidTest
```
